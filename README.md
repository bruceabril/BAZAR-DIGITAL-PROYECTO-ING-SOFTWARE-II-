# BAZAR-DIGITAL-PROYECTO-ING-SOFTWARE-II-
Bazar digital es un Sistema de comercio electrónico con catálogo multicategoría y atributos variables. Gestiona un carrito flexible con descuentos acumulables, extras por producto y diversos medios de pago simulados con reglas propias. Además, incluye notificaciones automáticas de reposición de stock, historial de pedidos y generación de facturas.
